# Reservation service

Owns the authoritative reservation lifecycle and interval availability.

## Responsibilities

- Accepts hold, confirmation and cancellation commands asynchronously.
- Uses database locking and interval constraints to prevent overlapping active reservations.
- Coordinates payment through durable messages; HTTP 202 means accepted, not completed.

## Technology

TypeScript, NestJS, PostgreSQL, RabbitMQ.
